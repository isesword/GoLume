## Checks

The exact commands and outputs are in `expression-liveness-checks.txt`.
The scalar suite, SIMD suite, runtime-disabled SIMD suite, race suite (including
`expr`), vet, GoDoc, generated SIMD consistency, kernel registry, structure check,
forced 128-bit focused tests, linux/amd64 SIMD build, and lazy demo are covered.
See the final result lines in that log for actual outcomes.

New regressions cover fixed-width and BOOL deep chains, nullable bitmap tails,
all ten numeric cast families, non-output CSE diamonds and repeated operands,
early/shared/duplicate projection roots, partial guarded regions, repeated batch
sizes, borrowed-input immutability, admission failure/retry, and cancellation.
Independent differential review and benchmark results are separate companion
reports. No remote CI run was requested, no PR was opened, and no merge was made.

All listed checks passed. The initial build failed only because VCS stamping
requires a Git checkout; rebuilding with `-buildvcs=false` passed. The materialized
source and connector-created commit retain the verified main base.

After the final retained differential and BOOL-export fault tests were added,
`go test ./...`, uncached SIMD `./expr`, uncached SIMD race `./expr`, `go vet
./expr`, GoDoc, and gofmt checks passed again. The retained differential harness
compares planned and unplanned execution over 128 seeded DAGs, eight batch sizes,
and both kernel modes (2,048 comparisons). Its reference retains one owner per
logical value; the independent separate-checkout review also matched pristine
main over 6,000 comparisons.
